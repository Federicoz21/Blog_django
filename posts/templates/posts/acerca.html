Acerca de

Quién está detrás del blog y para qué lo armé.

Sobre mí

Soy Federico Zangaro y estoy aprendiendo programación con Python. Arranqué escribiendo scripts simples en la consola, después vinieron las listas y diccionarios, las funciones, los módulos, las clases y los archivos JSON. Ahora estoy dando mis primeros pasos en desarrollo web con Django.

Me gusta entender cómo funcionan las cosas por dentro, así que cada vez que algo no anda prefiero buscar el porqué antes de copiar una solución.

Para qué es este sitio

Este blog es el proyecto que voy construyendo a lo largo del curso. Me sirve para practicar cada tema nuevo sobre algo concreto y, de paso, dejar registrado cómo fue avanzando.

La idea es que con el tiempo se convierta en un blog completo, donde se puedan publicar, editar y leer artículos desde el navegador.

Con qué está hecho

  • Python 3
  • Django 5.2
  • HTML y CSS
