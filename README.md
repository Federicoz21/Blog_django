# Blog Django

Proyecto base de un blog web desarrollado con Django.

## Descripción

Este proyecto contiene la estructura inicial de una aplicación web desarrollada con Django.

El proyecto se llama blog_project y cuenta con una aplicación principal llamada posts.

## Requisitos

- Python 3.11 o superior
- Django

## Instalación

1. Clonar el repositorio:

git clone URL_DEL_REPOSITORIO

2. Entrar a la carpeta del proyecto:

cd blog_django

3. Crear el entorno virtual:

python -m venv venv

4. Activar el entorno virtual en Windows PowerShell:

.\venv\Scripts\Activate.ps1

5. Instalar las dependencias:

pip install -r requirements.txt

6. Ejecutar el servidor de desarrollo:

python manage.py runserver

Luego abrir en el navegador:

http://127.0.0.1:8000/

## Aplicaciones

- posts: aplicación principal para las publicaciones del blog.

## Configuración

El proyecto utiliza:

- Idioma: español de Argentina (es-ar)
